## 数据获取最佳实践

1. 使用 csi300 或 csi500 等指数成分股作为股票池，避免全市场扫描
2. 财务数据为季度频率，已前向填充到日级别，可直接在日频策略中使用
3. 数据缺失或 NaN 时，过滤条件自动返回 False（该股票被排除）
4. 数据通过 DuckDB 缓存，首次获取后自动缓存到本地

## 财务字段详细说明（五表合并，ADR-007 Phase 3 + ADR-014 任务7）

## 概述

本章节详细说明系统可用的 20 个财务字段的含义、计算方法、数据来源与策略使用提示。
所有字段来自 miniqmt (xtquant) 的五张财务表合并提取：

- **利润表 (Income)**：反映企业经营成果
- **资产负债表 (Balance)**：反映企业财务状况
- **现金流量表 (CashFlow)**：反映企业现金流转
- **主要指标表 (Pershareindex)**：交易所预计算的每股指标与衍生指标
- **股本变动表 (Capital)**（ADR-014 任务7）：反映股本结构变化

字段统一存入 DuckDB 缓存 8 张细表（6 标量 + 2 长表 Top10），并基于真实公告日
（announce_date，来自 miniqmt 的 m_anntime 字段）做 PIT 对齐后前向填充到日频，
杜绝未来函数（详见 ADR-007）。

## 一、利润表字段 (Income)

### 1.1 收入与利润

#### 营业总收入 (revenue)
- **解释**: 企业在一定会计期间通过主营业务及其他业务取得的总收入
- **计算方法**: 利润表 "营业收入" 行项，含主营业务收入与其他业务收入
- **数据来源**: miniqmt Income 表 `revenue_inc` / `total_operating_revenue`
- **单位**: 元（绝对值，非比率）
- **典型量级**: 大型蓝筹数百亿至数千亿元；中小盘数亿至数十亿元
- **策略提示**: 关注同比增速（revenue_yoy）而非绝对值；增速持续提升代表成长性增强

#### 净利润 (net_profit)
- **解释**: 企业在一定会计期间实现的最终利润，扣除所有成本、费用、税收后归属股东的利润
- **计算方法**: 利润表 "净利润" = 营业总收入 - 营业成本 - 期间费用 - 所得税 + 投资收益 + 营业外收支净额
- **数据来源**: miniqmt Income 表 `net_profit_incl_min_int_inc`（含少数股东损益）
- **单位**: 元
- **策略提示**: 与经营现金流对比可识别利润质量；净利润高但 OCF 持续为负需警惕

### 1.2 每股指标

#### 每股收益 (eps)
- **解释**: 每股普通股创造的净利润，衡量每股盈利能力
- **计算方法**: `EPS = 归属普通股股东净利润 / 流通在外普通股加权平均股数`
- **数据来源**: miniqmt Income 表 `s_fa_eps_basic`（基本每股收益）
- **单位**: 元/股
- **典型量级**: 0.1 ~ 3.0 元/股为常见区间；> 1.0 通常视为盈利较强
- **策略提示**: 估值（PE）计算基础；注意送转股会导致 EPS 被动摊薄

### 1.3 成本与费用

#### 研发费用 (research_expenses)
- **解释**: 企业在研发活动中发生的各项费用，反映技术创新投入强度
- **计算方法**: 利润表 "研发费用" 行项（2018 年新准则后从管理费用单列）
- **数据来源**: miniqmt Income 表 `research_expenses`
- **单位**: 元
- **策略提示**: 研发费用 / 营业收入（研发强度）是科技、医药行业核心竞争力指标；
  研发投入持续高但暂未盈利的企业（如创新药）需结合管线进度评估

## 二、资产负债表字段 (Balance)

### 2.1 权益与资产

#### 所有者权益合计 (total_equity)
- **解释**: 企业资产扣除负债后由所有者享有的剩余权益，即净资产
- **计算方法**: `所有者权益 = 总资产 - 总负债`，含实收资本、资本公积、盈余公积、未分配利润等
- **数据来源**: miniqmt Balance 表（多字段兜底：`total_equity` / `total_parent_equity` / `incom_parent_equity`）
- **单位**: 元
- **策略提示**: ROE 计算的分母；关注归属母公司股东权益 vs 少数股东权益的区分

#### 总资产 (total_assets)
- **解释**: 企业拥有或控制的全部资产，反映企业规模
- **计算方法**: 资产负债表 "资产总计" = 流动资产 + 非流动资产
- **数据来源**: miniqmt Balance 表 `tot_assets`
- **单位**: 元
- **策略提示**: 与总负债对比判断杠杆水平；资产规模需结合周转率评估运营效率

#### 总负债 (total_liabilities)
- **解释**: 企业承担的需以资产或劳务偿付的全部债务
- **计算方法**: 资产负债表 "负债合计" = 流动负债 + 非流动负债
- **数据来源**: miniqmt Balance 表 `tot_liab`
- **单位**: 元
- **策略提示**: 与总资产对比计算资产负债率（debt_to_assets），判断财务风险

## 三、现金流量表字段 (CashFlow)

### 3.1 经营活动现金流

#### 经营活动现金流净额 (ocf)
- **解释**: 企业经营活动产生的现金流入与流出的差额，反映主业"真金白银"的造血能力
- **计算方法**: `OCF = 净利润 + 非现金支出(折旧、摊销) ± 营运资本变动`
- **数据来源**: miniqmt CashFlow 表 `net_cash_flows_oper_act`
- **单位**: 元
- **策略提示**: OCF 持续为正且大于净利润代表利润质量高（现金支撑）；
  OCF 持续为负即使利润高也需警惕资金链风险

### 3.2 投资活动现金流

#### 资本支出 (capex)
- **解释**: 企业购建固定资产、无形资产等长期资产支付的现金，反映扩张与产能投入
- **计算方法**: 现金流量表 "购建固定资产、无形资产和其他长期资产支付的现金"
- **数据来源**: miniqmt CashFlow 表 `cash_pay_acq_const_fiolta`
- **单位**: 元
- **策略提示**: `自由现金流 (FCF) = OCF - CapEx` 是衡量企业真实价值创造的核心指标；
  CapEx 持续高且 OCF 不能覆盖时，可能侵蚀长期股东价值

## 四、主要指标表字段 (Pershareindex，预计算值)

### 4.1 每股指标

#### 每股净资产 (bps)
- **解释**: 每股普通股对应的账面净资产，衡量每股的账面价值
- **计算方法**: `BPS = 归属普通股股东净资产 / 流通在外普通股股数`
- **数据来源**: miniqmt Pershareindex 表 `s_fa_bps`
- **单位**: 元/股
- **典型量级**: 3 ~ 15 元/股为常见区间
- **策略提示**: 市净率 (PB) 计算基础；破净（PB < 1）在银行、地产等重资产行业常见

#### 每股经营现金流 (ocf_per_share)
- **解释**: 每股普通股对应的经营活动现金流净额，衡量每股的现金创造能力
- **计算方法**: `每股经营现金流 = 经营活动现金流量净额 / 年末普通股总股本`
- **数据来源**: miniqmt Pershareindex 表 `s_fa_ocfps`
- **单位**: 元/股
- **策略提示**: 与 EPS 对比，若 ocf_per_share 持续低于 eps，说明利润含金量不足

### 4.2 偿债能力

#### 资产负债率 (debt_to_assets)
- **解释**: 负债总额占资产总额的比率，衡量企业财务杠杆与偿债风险
- **计算方法**: `资产负债率 = 总负债 / 总资产 × 100%`
- **数据来源**: miniqmt Pershareindex 表 `gear_ratio`（杠杆比率）
- **单位**: 比率（0 ~ 1 之间，或百分比）
- **典型量级**: 30% ~ 60% 为常见区间；> 70% 需警惕财务风险；银行/地产通常较高
- **策略提示**: 不同行业基准差异大，应跨期对比并参考行业均值

### 4.3 盈利能力

#### 净利率 (net_profit_margin)
- **解释**: 净利润占营业收入的比率，反映企业整体的盈利效率
- **计算方法**: `净利率 = 净利润 / 营业收入 × 100%`
- **数据来源**: miniqmt Pershareindex 表 `net_profit`（注意此处为比率指标，非利润额）
- **单位**: 比率（0 ~ 1 之间，或百分比）
- **典型量级**: 5% ~ 20% 为常见区间；> 20% 通常为高盈利行业（如白酒、医药）
- **策略提示**: 净利率提升通常代表规模效应或定价权增强，是优质企业的特征

#### 加权净资产收益率 (roe_weighted)
- **解释**: 按证监会第 9 号规则加权平均计算的净资产收益率，反映股东投入资本的回报效率
- **计算方法**: `ROE = P / (E0 + NP÷2 + Ei×Mi÷M0 - Ej×Mj÷M0)`
  - P = 报告期利润；NP = 报告期净利润；E0 = 期初净资产
  - Ei = 报告期新增净资产；Ej = 报告期减少净资产
  - M0 = 报告期月份数；Mi/Mj = 新增/减少净资产下一月起至报告期末的月份数
- **数据来源**: miniqmt Pershareindex 表 `equity_roe`（监管口径，比手算更准确）
- **单位**: 比率（0 ~ 1 之间，或百分比）
- **典型量级**: 8% ~ 20% 为优秀区间；> 15% 通常视为优质企业（巴菲特标准）
- **策略提示**: 这是监管披露口径的 ROE，优先于手算 roe 使用；
  注意季度数据为累计值，单季度需用本期减上期计算

## 五、衍生指标（Pershareindex 预计算优先，手算兜底）

### 5.1 同比增长指标

#### 净利润同比增长率 (net_profit_yoy)
- **解释**: 本期净利润相对上年同期的增长比率，衡量盈利成长性
- **计算方法**: `净利润同比增长率 = (本期净利润 - 上年同期净利润) / |上年同期净利润| × 100%`
- **数据来源**: miniqmt Pershareindex 表 `du_profit_rate`（预计算优先）；
  缺失时手算兜底
- **单位**: 比率（可为负，亏损扩大时负值更深）
- **典型量级**: -20% ~ +50% 为常见区间；> 30% 通常视为高成长
- **策略提示**: 注意分母为零或为负时的口径失真；关注增长质量（是否来自主营）

#### 营业收入同比增长率 (revenue_yoy)
- **解释**: 本期营业收入相对上年同期的增长比率，衡量收入成长性
- **计算方法**: `营业收入同比增长率 = (本期营业收入 - 上年同期营业收入) / 上年同期营业收入 × 100%`
- **数据来源**: miniqmt Pershareindex 表 `inc_revenue_rate`（预计算优先）；
  缺失时手算兜底
- **单位**: 比率
- **典型量级**: -15% ~ +40% 为常见区间
- **策略提示**: 收入增长与利润增长应匹配；增收不增利需关注成本费用变化

### 5.2 盈利能力指标

#### 净资产收益率 (roe)
- **解释**: 净利润与股东权益的比率，衡量股东投入资本的回报效率
- **计算方法**: `ROE = 净利润 / 股东权益 × 100%`
- **数据来源**: miniqmt Pershareindex 表 `du_return_on_equity`（预计算优先）；
  缺失时手算兜底（季度年化：Q1×4 / Q2×2 / Q3×4÷3 / Q4×1）
- **单位**: 比率（0 ~ 1 之间，或百分比）
- **典型量级**: 8% ~ 20% 为优秀区间；> 15% 通常视为优质企业
- **策略提示**: 与 `roe_weighted` 区别——本字段在预计算值缺失时用手算兜底，
  年化系数较粗糙；优先使用 `roe_weighted`（监管口径加权 ROE）

#### 销售毛利率 (gross_margin)
- **解释**: 毛利占营业收入的比率，反映产品/服务的基础盈利空间
- **计算方法**: `毛利率 = (营业收入 - 营业成本) / 营业收入 × 100%`
- **数据来源**: miniqmt Pershareindex 表 `gross_profit`（预计算优先）；
  缺失时手算兜底（需 total_operating_cost）
- **单位**: 比率（0 ~ 1 之间，或百分比）
- **典型量级**: 行业差异大；软件/医药 > 70%；制造业 20% ~ 40%；零售 < 20%
- **策略提示**: 毛利率稳定或提升通常代表定价权或成本控制能力；
  毛利率下滑需警惕竞争加剧或成本压力

## 六、股本变动表字段 (Capital，ADR-014 任务7)

### 6.1 股本结构

#### 总股本 (total_shares)
- **解释**: 公司发行在外的全部普通股股数，含限售股与流通股
- **计算方法**: 股本变动表 "总股本" 行项，反映最近一次股本变动后的总股数
- **数据来源**: miniqmt Capital 表 `total_capital`（候选兜底：`total_share` / `total_shr`）
- **单位**: 股
- **典型量级**: 大型蓝筹百亿股级；中小盘数千万至数十亿股
- **策略提示**: 与 `float_shares` 对比可计算流通比率；总股本激增
  通常因送转股、定增、配股等，需结合价格与 EPS 调整

#### 流通股本 (float_shares)
- **解释**: 公司发行在外、可在二级市场自由交易的普通股股数
- **计算方法**: 股本变动表 "流通股本" 行项，已扣除限售股
- **数据来源**: miniqmt Capital 表 `circulating_capital`（候选兜底：
  `float_share` / `float_shr` / `freeFloatCapital`）
- **单位**: 股
- **典型量级**: 通常小于 total_shares；流通比率 < 50% 需关注解禁风险
- **策略提示**: 流通股本变化影响市场流动性与 EPS 计算；
  限售解禁（流通股本骤增）是常见股价压力因素

## 七、PIT 对齐与使用注意事项

### 7.1 PIT（Point-in-Time）契约

所有财务字段在入库时已记录真实公告日（announce_date），日频面板通过
`_quarterly_to_daily` 前向填充：timestamp = T 的行只包含 announce_date <= T
的最新报告值，杜绝未来函数。

**策略使用直接读取日频面板即可**，无需关心公告日对齐——系统已处理。

### 7.2 季度年化注意事项

- 单季度 ROE / 净利率等比率指标为累计值，单季度值需用本期减上期
- 手算兜底的 ROE 年化系数：Q1×4 / Q2×2 / Q3×4÷3 / Q4×1，仅作粗略估算
- **优先使用 Pershareindex 预计算值**（roe_weighted / roe），监管口径更准确

### 7.3 字段缺失处理

- 数据缺失或 NaN 时，过滤条件自动返回 False（该股票被排除）
- 衍生指标（net_profit_yoy / revenue_yoy / roe / gross_margin）有手算兜底，
  原始字段（如 Pershareindex 预计算值）缺失率较高时可选手算值替代
