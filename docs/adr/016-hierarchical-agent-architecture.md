# ADR-016: 分层智能体架构


## 背景

原主图采用「带语言模型路由器的三子图直通」模式：意图分析在三个固定子图之间择一执行，本质是路由器而非智能体。该设计存在三方面局限：无法分解复合任务（例如「分析茅台并给出策略」）；子图产出对主图不透明（完整字典直接写入状态）；算子研发子图虽已能自研算子，但未与策略研发流同步接入——策略开发因算子缺失失败即中断，无法在同一流程内补齐后重试。

## 决策

我们将主图升级为分层智能体架构：MasterAgent（ReAct）负责任务分解与跨子图编排，各子图承担领域深度推理与执行。

### A. MasterAgent

基于 `create_react_agent` 与六项任务工具（子图或服务的薄封装，不重写领域逻辑）：

| 工具 | 职责 |
|------|------|
| `research_strategy(idea, constraints)` | 策略研发（ADR-018 后委托 ResearchAgent），返回最佳策略 YAML、指标与探索路径摘要 |
| `analyze_stock(query, symbols)` | 股票分析子图（五视角并行） |
| `infer_events(query)` | 事件推理子图 |
| `retrieve_memory(query, k)` | MemoryService |
| `web_search(query)` | kimi_web_search |
| `summarize(...)` | 内置，整合多工具结果 |

系统提示要点：复合请求先分解再调度；回答须基于工具返回的结构化证据，禁止编造。

### B. 算子缺口闭环（策略研发层内部）

算子研发工具（`list_operators` / `detect_operator_gap` / `develop_operator`）下沉至策略研发层（现 ResearchAgent 工具集），**不暴露给 MasterAgent**：

1. **避免抽象泄漏**：主智能体不应理解算子目录、OperatorSpec 或 DSL 领域概念，否则工具选择质量下降；
2. **时序正确性**：算子研发是策略研发流内的同步子任务（开发失败后在同一循环内研发算子并重试，或剪枝该假设方向）；上提至主智能体将导致死锁或时序错乱；
3. **闭环完整性**：研发成功重试与失败剪枝均在研发层工具集内完成；`develop_operator` 内部强制 `prove_causality`，自主注册算子须附带 reference_strategy 与 motivation，可回溯至触发运行。

### C. 策略研发编排（§C，已由 ADR-018 取代）

原决策「保留 HTR 六步骨架为唯一编排、策略研发不做全量 ReAct 化」已废止。实验表明纯 HTR 子图难以产出有效策略；外置 ReAct 与回测、算子工具结合可形成正反馈闭环。HTR 假设树与统计门保留为状态存储与硬性约束。原例外处理设计（`escape_hatch.py`：算子缺口检测、同步研发、重试；执行器失败分类、可修复走 refine、方向性失败直接剪枝）作为 ResearchAgent 工具内部实现参考保留。

### D. 防过拟合硬性约束

| 约束 | 实施位置 | 语言模型可否跳过 |
|------|---------|-----------------|
| 三段式数据分割 | 回测、OOS 节点与工具内部（配置区间强制） | 否 |
| OOS 合并门与统计验证门（ADR-022） | 合并路径：Walk-Forward 稳定性为硬性门控；DSR/PBO 为诊断（输入不齐时标记 `skipped`） | 否（硬性门控不可跳过；诊断不可静默视为通过） |
| 时点（PIT）对齐 | 数据层 VisibilityGuard | 否 |
| 算子目录白名单与因果证明 | DSL 解析期、`develop_operator` 内部 | 否 |
| 搜索策略（分支数、展开深度、剪枝时机） | decide / Agent 决策 | 在配置硬上界内可自主，树状态强制记录 |

**分界原则**：与证据相关的约束（回测、OOS 验证、步序因果）不可跳过；资源分配决策在硬上界内可由智能体自主决定。

## 后果

**正面**

- 复合请求可分解处理；算子缺口在研发流内同步闭环；工具集为薄封装，迁移风险较低。

**负面**

- ReAct 循环增加语言模型调用次数与 token 成本；分层调试复杂度上升（主智能体、子图、执行器三层），需工具调用审计日志；弱模型对工具选择的依赖增强，须配合高质量系统提示与少样本示例。

**中性**

- ADR-010 于 2026-08-30 起标记为 Deprecated（编排待删除；树状态与合并、统计验证门由 ADR-022 与 ResearchAgent 承接）；自我进化技能规格见 ADR-017（Deferred），解锁节奏见 ADR-022。
