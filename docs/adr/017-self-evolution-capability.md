# ADR-017: 自我进化能力（经验回写/热启动/元指标/失败反思/prompt自审）

日期: 2026-07
状态: Deferred

## 背景

从 ADR-016 拆出独立评审：自我进化优化的是任务执行过程而非策略本身，对策略质量的贡献是二阶且未验证的；ADR-015 统计门刚落地、尚无稳健策略基线，此阶段构建「自主改 prompt / 调参 / 反思架构」是在未夯实的地基上盖楼（自我腐化风险：无基线无法判断调整是改善还是劣化）；且体量大。

## 前置条件（全部满足后 Deferred -> Proposed）

1. ADR-015 三道统计门端到端验证有效（至少拦截一次过拟合 + 至少一个策略过全部门合并为 current best）；
2. MasterAgent 落地稳定（已满足）；
3. 系统端到端产出至少一个验证集表现稳健的策略作为基线。

## 决策概要

待前置满足后补充四项技能，**全自主落地 + 版本追溯**（不卡人工审批门，但所有变更可回溯、可回滚）：

1. **任务级经验回写与热启动**：任务结束 `reflect_and_record` 反思工具组合有效性，产出结构化 TaskExperience（tools_used / outcome / lessons / 有效与无效模式，`version` + `parent_sid` 谱系树）；新任务 `hot_start` 检索相似经验注入 system prompt。
2. **进化元指标与报告**：按日聚合策略研发成功率 / 耗时 / 失败模式 TOP / 算子目录增长等，`report_evolution` 产出趋势报告（可对比月度）。
3. **失败信号驱动自动反思**：双层检测（任务内同签名失败率 + 跨任务 `detect_stagnation`：连续无 OOS 改善 / 工具失败率超阈 / 耗时上升），产出 AdjustmentProposal 物质，主智能体可自主执行（调参直接落地，改 prompt 走技能 4）。
4. **Prompt 自审计与修订**：`audit_prompts` 扫描退役语法 / 字段表不一致 / frontmatter 缺失 / 示例日期过时；`revise_prompt` 产新版本文件（`foo_v2.md`，原文件保留，加载取最高版本）。安全护栏：渲染验证 + DSL 解析验证 + 元指标发现修订后失败率上升自动回滚并标记有害。

所有经验 / 指标 / 失败分析 / 调整提案统一存 Substance（form=KNOWLEDGE，metadata 记录谱系：version / parent_sid / signal_type / applied 等）。

## 后果

- 正面（前置满足后）：元认知能力（提前发现 prompt 契约问题、成功率下降、工具失败模式）；相似任务热启动减少重复探索。
- 负面：进化工具使主智能体工具总数达 13（弱模型选择质量风险，需工具分组/两级分发）；全自主修订有自我腐化与误判风险（版本追溯 + 自动回滚是底线非充分保证）；token 成本上升。
