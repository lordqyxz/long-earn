# ADR-013: 回测引擎准确性原则与陷阱清单

日期: 2026-07-11
状态: Accepted
关联: ADR-005（事件驱动回测）/ ADR-008（并行回测）/ ADR-009（算子目录）

## 动机

含未检测偏差的回测结论比没有回测更危险--它给虚假信心，投真金白银后亏损。本 ADR 按七个维度梳理量化回测已知错误（成因 -> 检测方法），作为测试设计与代码审查的纲领。**各陷阱的防护覆盖状态以代码与 `tests/unit/` 为准，不在本文维护百分比。**

## 七维陷阱清单

### 1. 数据正确性（Data Integrity）

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| D1 | 幸存者偏差（用当前成分股回测历史，退市/ST 被剔） | 业绩系统性高估（常 2-5%/年）；universe 快照日期校验 + PIT 警告 |
| D2 | 未排序数据上 ffill（未来值填到过去） | 财务因子虚高；因果性测试 |
| D3 | 用财报截止日而非披露日作可见起点 | 经典未来函数；PIT 对齐测试（公告日前断言 NaN） |
| D4 | 多源复权方式不一致 | 收益率系统性偏差；provider 强制声明 adjust 策略 |
| D5 | 拆分/分红未复权（除权跳空） | 虚假涨跌幅；复权因子校验 |
| D6 | 停牌日 ffill 后误判可交易 | 虚假交易；成交量=0 拒单 |

### 2. 时序偏差（Temporal Bias）

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| T1 | T 日信号 T 日成交 | 业绩显著虚高；T+1 执行检查 + 因果性测试 |
| T2 | 指标计算用未来数据（rolling 未对齐等） | 因子偷看未来；可见性守卫 + 算子因果性证明 |
| T3 | 回测区间选择偏差 | 只在特定市场环境有效；多区间 + Walk-Forward OOS |
| T4 | Walk-Forward 训练/测试时间重叠 | OOS 虚高；严格时序分割校验 |
| T5 | 信息到达时间错位（收盘前新闻当次日可用） | 事件策略虚高；披露时间戳对齐测试 |
| T6 | warmup 漏算致因子前视截断 | 预取区间短于真实回溯需求 -> 因子前若干 bar 全 NaN -> `rank_top` 选不出股 -> `trade_count=0` 误判退化（关联 C5）；`compute_warmup_days` 覆盖全部回溯参数键（period/periods/window/span/fast/slow/signal）+ signals 算子步骤（2026-08 已修复，`backtest/engine/dsl.py`） |

### 3. 交易执行（Execution Fidelity）

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| E1 | 市价单全额成交假设（无视流动性） | 大单策略严重虚高；成交量参与率限制 |
| E2 | 固定滑点而非动态冲击模型 | 低估大单成本；冲击模型验证 |
| E3 | 佣金最低 5 元/单未实现 | 高频/小资金策略虚高；佣金计算测试 |
| E4 | 卖出印花税遗漏（A 股万五） | 高换手策略虚高；税费计算测试 |
| E5 | 沪市过户费遗漏（双向万分之 0.1） | 沪市成本低估；过户费测试 |
| E6 | 用 bar 内最优价而非保守价成交 | 限价单策略虚高；保守成交测试 |
| E7 | 部分成交后剩余被丢弃 | 持仓与模拟不符；partial_fill 追踪 |
| E8 | 盘中决策假设以收盘价成交 | 趋势策略虚高；信号-成交时戳检查 |

### 4. 市场微观结构（A 股制度）

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| M1 | 涨停可买 / 跌停可卖 | 封板策略严重失真；涨跌停拒单测试 |
| M2 | T+1 制度忽略（当日买当日卖） | 日内反转虚高；T+1 约束测试 |
| M3 | 停牌期间照常交易 | 虚假交易；停牌拒单测试 |
| M4 | 最小交易单位忽略（100 股/手） | 持仓偏差；最小单位检查 |
| M5 | 价格档位忽略（0.01/0.001） | 限价单无效；档位对齐检查 |
| M6 | 涨跌停价不取整到分 | 风控判断偏差；`round(price, 2)` 验证 |

### 5. 投资组合与风控

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| P1 | 现金不足抛异常终止而非跳过 | 回测不完整；现金不足跳过测试 |
| P2 | 行业集中度无限制 | 集中度风险；行业集中度测试 |
| P3 | 有止损无止盈 | 浮盈回吐失控；止盈触发测试 |
| P4 | max_turnover 配置无效 | 配置形同虚设；换手率检查测试 |
| P5 | 现金不足时融资买入（隐性杠杆） | 不现实杠杆；现金约束检查 |
| P6 | 同 bar 多信号未合并订单 | 交易次数虚高；订单合并检查 |

### 6. 指标计算

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| C1 | 年化公式不一致（夏普算术 / 波动几何） | 口径混乱；numpy 直算比对 |
| C2 | 无风险利率假设 R_f=0 | Alpha 虚高；参数化 R_f 测试 |
| C3 | 样本量不足仍输出指标（3 天夏普 10+） | 极端值误导；min_trading_days 门槛 |
| C4 | 日收益累乘 vs 简单累加偏差 | 长期回测偏差显著；几何/算术比对 |
| C5 | 退化策略混入最优（filter 全筛掉 -> 空仓零收益被当「无亏损策略」） | 网格搜到「啥都不做」的伪最优；`metrics_unreliable` / `degenerate` 过滤 |

### 7. 工程与审计

| # | 陷阱 | 危害 / 检测 |
|---|------|------------|
| A1 | 异常路径/并行 worker 审计丢失 | 无法追溯失败；审计完整性测试 |
| A2 | 审计时间戳用 `now()` 非单调时钟 | 重放时序混乱；时间戳单调性测试 |
| A3 | 审计写失败抛异常终止回测 | 小问题丢整轮回测；审计降级测试 |
| A4 | RUN_START 缺完整输入，无法重放 | 无法重建回测；输入完整性测试 |

## 检测方法论（按效力排序）

1. **因果性测试**（最强大单一手段）：跑一次得权益曲线 E1；大幅扰动回测区间后半段价格（模拟「未来被改写」）再跑得 E2；断言前半段逐日权益不变。同时覆盖 T1/T2/D2。实现：`test_operator_dsl_causality.py`。
2. **PIT 对齐测试**：构造已知披露日期的财报，验证披露前 NaN、披露日起可见。覆盖 D3。
3. **对比测试**：numpy/pandas 直算期望值与引擎输出 `pytest.approx` 比对。覆盖 C1-C4。
4. **合规约束测试**：构造已知应被拒绝的交易场景，验证正确跳过并写 ORDER_SKIPPED 审计。覆盖 M/E 类。
5. **回归测试**：对已修复缺陷构造场景防回退（`@pytest.mark.regression`）。

每个准确性测试至少断言之一：正确执行 / 正确拒绝（审计事件）/ 数值相等 / 无泄漏（前半段权益不变）。
